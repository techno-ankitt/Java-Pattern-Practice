## ▶️ How to Run

1. Clone this repository.
2. Open the project in VS Code or any Java IDE.
3. Compile the program:

   ```bash
   javac pattern_ques_prectice.java
   ```
4. Run the program:

   ```bash
   java pattern_ques_prectice
   ```
